# MiniMax H3 Codex Skills

This repository contains two standalone Codex skills:

- [`h3-prompt-writing/`](h3-prompt-writing/) — write MiniMax H3 video prompts.
- [`runninghub-minimax-h3/`](runninghub-minimax-h3/) — generate videos with the RunningHub MiniMax H3 app using its included, independent local key vault, task ledger and executor.

Each skill directory includes its `SKILL.md` and required supporting files. The H3 service uses Node.js built-in modules and runs independently of other applications.
